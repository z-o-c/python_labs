# Лабораторная работа 9: Управление группой студентов с хранением в CSV

## Реализованные компоненты

### 1. Класс `Group` ([group.py](src/lab09/group.py))

Класс для управления коллекцией студентов с хранением данных в CSV файле. Расширяет функциональность модели `Student` из lab08, добавляя операции CRUD (Create, Read, Update, Delete) для работы с группой студентов.

**Поля:**
- `storage_path: Path` — путь к CSV файлу хранилища
- `students: list[Student]` — список объектов Student в памяти

**Методы:**

#### `__init__(self, storage_path: str | Path) -> None`
Инициализация группы студентов и загрузка данных из CSV файла.

**Параметры:**
- `storage_path` — путь к CSV файлу для хранения данных

#### `_load(self) -> None` *(приватный метод)*
Загрузка данных из CSV файла в память. Создает объекты `Student` из строк CSV файла.

**Логика:**
- Проверяет существование файла
- Читает CSV с помощью `csv.DictReader`
- Создает объекты `Student` из каждой строки
- Обрабатывает поля: `fio`, `birthdate`, `group`, `gpa`

#### `_save(self) -> None` *(приватный метод)*
Сохранение списка студентов из памяти обратно в CSV файл.

**Логика:**
- Открывает файл для записи с кодировкой UTF-8
- Использует `csv.DictWriter` для записи данных
- Записывает заголовки: `fio`, `birthdate`, `group`, `gpa`
- Сериализует каждый объект `Student` в строку CSV

#### `add(self, student: Student) -> None`
Добавление нового студента в группу.

**Параметры:**
- `student` — объект `Student` для добавления

**Логика:**
- Добавляет студента в список `self.students`
- Автоматически сохраняет изменения в CSV файл

#### `list(self) -> list[Student]`
Получение списка всех студентов в группе.

**Возвращает:**
- Список всех объектов `Student`

#### `find(self, substr: str) -> list[Student]`
Поиск студентов по подстроке в ФИО (регистронезависимый).

**Параметры:**
- `substr` — подстрока для поиска в ФИО

**Возвращает:**
- Список объектов `Student`, у которых `substr` входит в `fio`

#### `remove(self, fio: str) -> None`
Удаление студента по полному совпадению ФИО.

**Параметры:**
- `fio` — ФИО студента для удаления

**Логика:**
- Фильтрует список студентов, исключая студента с указанным ФИО
- Автоматически сохраняет изменения в CSV файл

#### `update(self, fio: str, **fields) -> None`
Обновление данных существующего студента.

**Параметры:**
- `fio` — ФИО студента для обновления
- `**fields` — именованные аргументы для обновления полей (fio, birthdate, group, gpa)

**Логика:**
- Находит студента по ФИО
- Обновляет указанные поля с помощью `setattr`
- Валидирует наличие полей у объекта `Student`
- Автоматически сохраняет изменения в CSV файл

**Исключения:**
- `ValueError` — если у студента нет указанного поля

### 2. Формат данных CSV

Файл `students.csv` содержит данные студентов в формате CSV с заголовками:

```csv
fio,birthdate,group,gpa
Иванов Иван,2003.10.10,БИВТ-21-1,4.3
Сидоров Сидор Сидорович,2003.10.10,БИВТ-21-2,4.4
Петров Пётр Петрович,2003.10.10,БИВТ-21-3,4.7
```

**Поля:**
- `fio` — ФИО студента (строка)
- `birthdate` — дата рождения в формате YYYY.MM.DD (строка)
- `group` — название группы (строка)
- `gpa` — средний балл (число с плавающей точкой, 0-5)

### 4. Примеры использования

```python
from lab09.group import Group
from lab08.models import Student

# Создание группы и загрузка данных из CSV
group = Group("data/lab09/students.csv")

# Добавление нового студента
new_student = Student(
    fio="Васильев Василий Васильевич",
    birthdate="2005.01.01",
    group="BIVT-25",
    gpa=4.5
)
group.add(new_student)

# Поиск студентов
romanov_students = group.find("Романов")
print(f"Найдено студентов: {len(romanov_students)}")

# Обновление данных студента
group.update("Васильев Василий Васильевич", gpa=4.7)

# Удаление студента
group.remove("Романов Роман Романович")

# Получение всех студентов
all_students = group.list()
for student in all_students:
    print(student)
```

### 5. Архитектура решения

Класс `Group` реализует паттерн Repository для работы с данными студентов:

- **Загрузка:** CSV → объекты Student в памяти
- **Операции:** манипуляции с объектами в памяти
- **Сохранение:** объекты Student → CSV

![Архитектура](/images/lab09/img03.png)

Все изменения автоматически синхронизируются с CSV файлом, обеспечивая персистентность данных между запусками программы.
