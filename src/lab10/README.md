## Краткая теория

**Стек (Stack)** — структура данных типа LIFO (последним пришёл — первым ушёл). Применяется в рекурсии, вычислении выражений и т.д.
- Основные операции: push (добавление), pop (удаление), peek (просмотр верхнего), is_empty (проверка пустоты).
- Все операции выполняются за O(1).

**Очередь (Queue)** — структура данных типа FIFO (первым пришёл — первым ушёл). Используется в алгоритмах поиска в ширину, очередях печати и др.
- Основные операции: enqueue (добавить), dequeue (удалить), peek (просмотр первого), is_empty.
- Все операции — O(1), если использовать deque.

**Связный список (SinglyLinkedList)** — набор элементов (узлов), где каждый содержит ссылку на следующий. Позволяет эффективно вставлять и удалять элементы в любом месте, но медленный доступ по индексу.
- Операции: append (в конец), prepend (в начало), insert (по индексу), remove (по значению), итерирование, len, is_empty.
- Основные — O(1) (append/prepend), остальное O(n).

## Реализованные классы и примеры

**Stack** (`src/lab10/structures.py`):
```python
s = Stack()
s.push(1)
s.push(2)
s.pop()          # 2
print(s.peek())   # 1
print(s.is_empty()) # False
```

**Queue** (`src/lab10/structures.py`):
```python
q = Queue()
q.enqueue('a')
q.enqueue('b')
q.dequeue()       # 'a'
print(q.peek())   # 'b'
print(q.is_empty()) # False
```

**SinglyLinkedList** (`src/lab10/linked_list.py`):
```python
lst = SinglyLinkedList()
lst.append(1)
lst.prepend(0)
lst.insert(1, 0.5)
lst.remove(0.5)
for x in lst:
    print(x)
print(len(lst))
```


- **Stack** и **Queue** (на основе list/deque) демонстрируют максимальную производительность для типичных операций: все — O(1).
- **SinglyLinkedList** быстро добавляет/удаляет в начале и конце, но вставка и удаление по индексу требуют линейного времени O(n).
- **Stack** быстрее, чем список Python, если требуется только LIFO.
- **Queue** на deque быстрее очереди на list благодаря отсутствию необходимости сдвигать элементы.

**Вывод:**
- Для стека и очереди используйте list (stack) и deque (queue) для максимальной скорости.
- Связный список выгоден, если планируется частое добавление/удаление не в конце массива.
